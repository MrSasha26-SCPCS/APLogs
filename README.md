# APLogs
SCP: CS plugin

Добавляет логи в админ панель с возможностью скопировать информацию. Для того, чтобы админ получил доступ к ним, добавьте `logs` в его права. По умолчанию есть лишь логи заходов и убийств. В последнем случае можно копировать сообщение целиком, ник и айди жертвы и убийцы.

**Для разработчиков:** чтобы вызвать лог, воспользуйтесь хуком `APLog` и передайте первым параметром текст, вторым (необязательно) - названия кнопок для копирования, третим (тоже необязательно) - тексты для копирования (разделяются символом `|`). Пример: ```
HookManager.Run("APLog", "Какая-то важная инфа. Ник: sdsfcdfg. Айди: 123456767",
"сообщение целиком|ник|айди", 
"Какая-то важная инфа. Ник: sdsfcdfg. Айди: 123456767|sdsfcdfg|123456767");
```
